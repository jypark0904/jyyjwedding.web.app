기존 주소: https://jyyjwedding.web.app/
신부 전용 주소: https://yjjywedding.web.app/
신부 전용 로컬 파일: bride.html (node scripts/build-bride.mjs로 생성)
신부 전용 부모님 계좌 설정: bride-accounts.json
신랑 아버지 박승동·어머니 최정남 항목은 처음에 닫혀 있으며 이름을 눌러 열고 닫습니다.
신랑 부모님 은행·계좌번호는 빈칸이며 복사 버튼은 비활성화됩니다.
신부 전용 갤러리: 기존 12장 뒤에 모청픽 14.jpg → 14_NEW.jpg → 15.jpg를 추가한 총 15장.
                   기본 9장, 더보기 6장. 추가 목록은 bride-gallery.json에서 관리합니다.

1. 확인하기
   index.html을 Chrome, Edge, Safari 등 브라우저에서 열어주세요.
   index.html, style.css, app.js, assets 폴더는 같은 폴더에 두어야 합니다.
   사진·글꼴·애니메이션·캘린더·갤러리는 로컬 파일로 작동합니다.
   실제 지도와 외부 길찾기는 인터넷 연결이 필요합니다.
   처음에는 초록 하트와 진행률을 표시하며, 모든 사진과 글꼴이 준비되면 청첩장이 나타납니다.
   사진에는 갤러리 확대용 사진도 포함합니다. 로딩 실패 시 다시 시도하기를 눌러주세요.

2. 구성
   표지: 01 → 12 → 기존 청첩장 표지(반지) 사진 슬라이드. 자동 재생/멈춤, 터치 넘기기.
         5.2초 간격으로 전환하며, 두 번째 사진은 조금 확대하여 표시합니다.
         이름·일시·장소는 표지 사진과 INVITATION 사이에서 수직 중앙으로 배치합니다.
   초대글: 청첩장 AI의 본문과 예식 정보.
   캘린더: 2026년 11월 14일 토요일 오후 4시, 한국 시간 기준 남은 시간.
   갤러리: 총 12장. 원본 번호 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 15 → 11 순서.
           첫 9장은 정사각형 그리드로 표시하고, 더보기로 나머지 3장을 표시합니다.
           12·13·14번은 갤러리에서 제외했습니다. 15번은 모청픽 폴더의 15_NEW.jpg를 사용합니다.
           터치하여 확대, 좌우 넘기기, 확대/축소, Esc 또는 닫기.
   오시는 길: 지도 조작 잠금, 주소 복사,
               카카오·네이버·구글·티맵 길찾기, 전화 및 교통 안내.
   마음 전하기: 신랑·신부의 계좌를 항상 표시합니다. 전달받은 국민은행 계좌를 반영했습니다.
   소식 공유: 모바일 기본 공유창(카카오톡 등 선택 가능), 초대글 복사.
   하단: 하단커버 (2).jpg의 두 번째 사진을 3:4 원래 비율로 고정 표시합니다.
         JY & YJ 모노그램, 감사 인사와 공유 버튼이 이어집니다.
   파비콘: 아이보리 배경의 선명한 초록 하트. assets/icons/favicon.svg를 사용합니다.
   축하 메시지 기능은 포함하지 않았습니다.

3. 사진 색상
   표지 세 번째 컷은 assets/photos/original-13.jpg의 반지 사진 원본을 사용합니다.
   원본 출처는 F드라이브 결혼 폴더의 13.jpg이며, 갤러리 사진의 선택·삭제와는 별개입니다.
   표지 원본 파일과 색상 프로파일은 그대로 유지하며 사진 위 음영은 제거했습니다.
   표지 세 번째 사진은 화면에서만 약한 선명도·대비·채도 조정을 적용합니다.
   CSS .slide-detail img의 filter를 none으로 바꾸면 원본 표시로 돌아갑니다.
   갤러리와 하단 웹용 사진도 원본 색상 프로파일을 유지합니다.
   모청픽 폴더와 AI 원본은 수정하지 않았습니다.

4. 실제 계좌 입력
   app.js 맨 위 WEDDING.accounts의 bank, number, holder를 수정하면 됩니다.
   groom은 신랑, bride는 신부입니다.
   예시: { bank: '은행명', number: '실제 계좌번호', holder: '박재용' }
   실제 숫자 계좌가 입력되면 복사 버튼이 활성화됩니다.

5. 소식 공유
   로컬 파일 주소는 다른 분이 열 수 없으므로 로컬에서는 초대글을 공유합니다.
   공개 HTTPS 주소에 올린 뒤에는 해당 주소를 자동으로 공유합니다.
   또는 app.js의 WEDDING.publicUrl에 실제 공개 주소를 입력해주세요.
   모바일 기본 공유창을 지원하지 않으면 초대글 복사 창이 열립니다.
   카카오 전용 SDK는 연결하지 않았으며, 카카오톡 앱을 기본 공유창에서
   선택하거나 복사한 초대글을 붙여넣어 공유할 수 있습니다.
   티맵·네이버 앱 연결은 해당 앱이 설치된 모바일 기기에서 사용합니다.
